# Getting help

- **How do I…?** Start with the [README](README.md): install, HTTPS, phone, configuration, backups and upgrades.
- **Something is broken:** open a [bug report](https://github.com/Silent-Protocol-Inc/folio/issues/new/choose) with your Folio version, how you run it, and the logs (`docker compose logs`, or `folio.log` for native installs). Remove anything private first.
- **An idea:** open a [feature request](https://github.com/Silent-Protocol-Inc/folio/issues/new/choose).
- **A security problem:** don't open an issue; follow [SECURITY.md](SECURITY.md).

Folio is maintained by a small team, so answers can take a few days. Never post real financial data, passwords or session cookies in an issue.
